# ADR-0005：LLM-as-Judge 采用双向评估以对冲位置偏差

- **状态**：已采纳
- **日期**：2024-10
- **决策者**：核心开发

---

## 背景

评测体系需要给 Agent 产出打分。人工标注成本高、不可扩展，因此使用 LLM 作为裁判
（LLM-as-Judge）。但 LLM 裁判有已知的系统性偏差：

1. **位置偏差**：成对比较时倾向选择先出现的选项
2. **长度偏差**：倾向给更长的回答更高分
3. **自我偏好**：倾向给与自己风格相似的输出更高分
4. **正向偏差**：直接问「这个回答好吗」时倾向说好

如果不处理，评测结果会**系统性失真**，而失真的评测比没有评测更危险——
它会让人基于错误信号做出优化决策。

## 决策

对每个样本执行**两次方向相反的评估**，取平均并检测矛盾：

- **正向**：把这些产出当作待评价对象，问它**好在哪里**
- **反向**：把这些产出当作待审查对象，问它**有什么缺陷**

有参考答案时，两次评估**交换产出的位置**，使位置偏差在平均中被抵消。

```
正向: [产出A, 产出B] → 评分
反向: [产出B, 产出A] → 评分（位置交换）
最终: 逐维度取平均
```

### 关键实现规则

**1. 逐维度取平均，但通过与否取「合取」**

```python
passed = forward.passed and reverse.passed   # 保守：任一方认为不通过即不通过
```

正向偏向说好、反向偏向说差，取合取意味着「两次都认为好才算好」。
这比取平均更严格，避免正向偏差单方面把不合格的产出抬过线。

**2. 矛盾检测 → 置信度降权**

```python
_INCONSISTENCY_THRESHOLD = 1.0   # 两方向评分差超过 1 分视为矛盾

@property
def confidence(self) -> float:
    if self.inconsistent:
        return 0.5      # 明确降权，而不是当作有效评分
    return self._confidence
```

矛盾的样本在聚合时按置信度加权，并单独统计 `inconsistent_judge_rate`。
这个比率本身就是一个有价值的指标——**它高说明评价标准模糊或任务定义不清**。

**3. 增加 `conciseness` 维度对冲长度偏差**

评判维度为 `correctness` / `completeness` / `conciseness` / `actionability`。
显式的简洁性维度让「啰嗦但完整」不再自动占优——否则长度偏差会通过
completeness 悄悄进入评分。

**4. 温度固定为 0**

保证可复现。评测结果的稳定性比多样性重要。

**5. 有参考答案时交换位置**

无参考答案时位置无意义（都是"待评价产出"）；有参考答案时，
「产出 vs 参考答案」的相对位置会引入偏差，因此在反向评估中交换。

## 备选方案

### 方案 A：单次评估

**否决**：位置偏差、正向偏差完全暴露在结果里，且无法检测。

### 方案 B：多次采样 + 多数投票

**优点**：实现简单，能降低随机噪声。

**否决**：缓解的是**随机**误差，而位置偏差是**系统性**的。
多次采样都会倾向同一侧，投票无法消除系统性偏差。
且成本是 N 倍而非 2 倍。

### 方案 C：用多个不同模型交叉评判

**优点**：可降低单模型自我偏好。

**否决**：成本高，且不同模型的偏差方向未经验证，可能相互叠加而非抵消。
作为未来选项记录（架构上 `JudgeBackend` 是 Protocol，可替换实现）。

### 方案 D：双向评估（采纳）

**优点**：直接针对已知偏差的**方向**做对冲，成本仅 2 倍，且能产出矛盾指标。

**代价**：调用次数翻倍；矛盾检测阈值需要人工设定（1.0 是基于 0–10 分制经验选择）。

## 后果

### 正面

- 位置偏差与正向偏差在方向上被对冲
- `inconsistent_judge_rate` 提供了「评价标准是否清晰」的间接信号
- 置信度加权让矛盾的评分不会污染聚合结果
- 温度 0 + 双向评估使结果可复现（有测试守护）

### 负面

- 评测成本翻倍
- 取合取使 pass 判定偏严格，`judge_pass_rate` 更保守
- 矛盾阈值 `1.0` 是经验值，缺乏理论依据（已在代码中标注）

### 已识别的局限

- **自我偏好偏差未处理**：裁判模型若与被评模型同源，仍会偏高。
  ADR 中记录，作为未来引入异构裁判的动机。
- **`_extract_json` 的健壮性**：模型可能不按格式输出，实现了
  markdown 代码块 + 平衡括号两种回退，但仍可能失败并触发矛盾标记。
